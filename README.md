# Сборщик логов

> **Задание А.** Скрипт читает `/var/log/syslog` (или `/var/log/auth.log`), фильтрует события по ключевым словам и формирует отчёт в файл `report.txt` (по умолчанию).

## Файлы

| Файл | Описание |
|------|----------|
| [`script.sh`](script.sh) | сам скрипт |
| [`sample_output.txt`](sample_output.txt) | пример отчёта |

## Запуск

```bash
chmod +x script.sh
sudo ./script.sh
```

`sudo` нужен, потому что логи в `/var/log` может читать только root или группа `adm`.

## Параметры

Все параметры необязательные.

| Параметр | Что задаёт | По умолчанию |
|----------|------------|--------------|
| `-k "слово1\|слово2"` | ключевые слова для фильтрации (регистр не важен) | `error\|fail\|warning\|critical\|denied\|refused\|invalid\|panic` |
| `-o файл` | файл отчёта | `report.txt` |
| `-n N` | сколько последних событий вывести | `20` |
| `-h` | справка | |

Источник выбирается автоматически: `/var/log/syslog` → `/var/log/auth.log` → `journalctl`.

## Пример

Файл `sample_output.txt` получен командой:

```bash
./script.sh -k "info|warning|fail" -n 50 -o sample_output.txt
```

Фрагмент отчёта (полностью — в [`sample_output.txt`](sample_output.txt)):

```
1. ОБЩАЯ СТАТИСТИКА
======================================================================
  Всего строк в логе:     5190
  Найдено событий:        2139 (41.2%)

2. СОБЫТИЯ ПО КЛЮЧЕВЫМ СЛОВАМ
======================================================================
  info            2136  ########################################
  warning            0
  fail               3

3. ТОП-10 ПРОЦЕССОВ С СОБЫТИЯМИ
======================================================================
     2136  qemu-ga
        2  systemd
        1  zabbix_agentd
```
